⚙ ربط مستودع GitHub

ضع ملفات الإكسل داخل مستودعك على GitHub (عام، أو خاص مع رمز وصول) وسيقرأها النظام تلقائياً عند الضغط على «تحديث البيانات». الأسماء المتعرَّف عليها: المبيعات، مردودات المبيعات، الحسم الممنوح، تكلفة البضاعة المباعة (مدين/دائن)، إيرادات مختلفة، المصاريف.

خطوات سريعة: ① أنشئ مستودعاً عاماً على GitHub  ② ارفع ملفات الإكسل بأسماء أوراقها (المبيعات.xlsx …)  ③ الصق الرابط هنا واحفظ  ④ اضغط ⟳ تحديث البيانات في أي وقت لجلب أحدث نسخة.
